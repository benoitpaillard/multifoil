# Historical source overlay

These files preserve the numerical sources used before the conditional
monotone-paneling recovery, and the original retry helper before its cached-exit
status correction. SHA256 values are in sha256.json.

Restore the corresponding files in an isolated copy of the project to reproduce
older NLR7301 pilot manifests or the initial TN808 preprocessing failures.
Do not relabel those archived results as calculations from the changed solver.
New runs with the updated solver require a new output directory.
